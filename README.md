# Strymio — página do aplicativo

Página pública do Strymio, aplicativo pessoal para Android e Android TV que organiza e reproduz
listas M3U próprias.

Serve como endereço oficial do aplicativo no cadastro da API do TMDB.

- `index.html` — a página
- `icon.png` — ícone do aplicativo (512×512)

Publicada pelo GitHub Pages a partir da branch `main`, pasta raiz.

Este produto usa a API do TMDB, mas não é endossado nem certificado pelo TMDB.
